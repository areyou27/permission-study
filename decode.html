App code decoder

Paste the "App code" column from the form's responses below (or the whole export; every code in the text is found). Codes look like SS1-B-ADN. Everything runs in this page; nothing is uploaded.

A code is SS1, then the version (A plain, B explained), then one letter each for location, camera, and microphone: A Allow · D Don't Allow · N Prompt not shown. A leading P marks a pilot run. The app code is the record to trust: Google Forms lets a person change a prefilled answer, so compare the code with the Version and decision columns and keep the code when they disagree.
